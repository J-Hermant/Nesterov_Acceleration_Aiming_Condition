
# Nesterov_Acceleration_Aiming_Condition

In this supplement, we provide the Python code to reproduce our experiments and generate the figures of the paper ["Acceleration for Polyak–Łojasiewicz Functions with a Gradient Aiming
Condition"](https://arxiv.org/pdf/2602.10022). Simply run the following codes to generate the associated figures:
 - 1d_functions.py generates left plot of Figure 1, CV rates of left column of the table in Figure 1, Figure 2, Figure 7, Figure 8 and Figure 11.
 - 2d_functions.py generates the right plot of Figure 1, and the CV rates of the right colum of the table in Figure 1.
 - bad_example.py generates Figure 3 and Figure 10.
 - worst_instance_pl.py generates Figure 4 and Figure 5.
 - functions.py includes useful functions involved in other .py files.
